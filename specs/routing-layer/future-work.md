# Routing layer — tracked future work

Future work items previously maintained in this document have been converted to tracked GitHub issues in this
repository.

Track, filter, and plan implementation work via the [GitHub Issues tracker][issues].

## Organization & labels

Issues derived from future work items are tagged with labels representing their functional focus area and logical order:

- **[`fw:1`][label-fw1]**: Endpoint circuit breakers, provider quota exhaustion fast-skip, and active health recovery.
- **[`fw:2`][label-fw2]**: Workflow-specific horizon semantics for non-coding planning and operations.
- **[`fw:3`][label-fw3]**: Comparative empirical measurement of observed cache-read ratios across endpoints.
- **[`fw:4`][label-fw4]**: Empirical cache-class eligibility guards based on measured token shares.
- **[`routing`][label-routing]**: All routing layer issues and enhancements.

Please file and track any new proposals, enhancements, or bug reports as GitHub issues using these labels.
